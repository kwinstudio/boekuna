Betaling

Zo werkt het abonnement.

Betaalde abonnementen lopen via Stripe Checkout. Je abonnement en betaalmethode kun je daarna vanuit Boekuna beheren.

Wanneer betaal ik als ik bij de eerste 100 hoor?

Vandaag betaal je €0. Stripe slaat je betaalmethode op voor het abonnement. Na 90 dagen start het normale maandtarief van het gekozen plan automatisch, tenzij je vóór die tijd opzegt.

Wat als ik niet bij de eerste 100 hoor?

Dan start het gekozen betaalde abonnement direct tegen €9,95 of €20 per maand, exclusief toepasselijke btw.

Kan ik opzeggen?

Ja. Betaalde abonnementen zijn maandelijks en worden vanuit het abonnementsbeheer in Boekuna via Stripe beheerd.

Wat gebeurt er als ik mijn maandlimiet bereik?

Je bestaande administratie blijft beschikbaar. Nieuwe slimme documentanalyses worden geblokkeerd totdat je bundel wordt vernieuwd, je upgrade of de volgende maand begint.
