# Fotoswipe build status

This isolated app is being prepared for TestFlight. Bundle ID `nl.zichtwerfstudio.fotoswipe` is registered to the existing Apple team. The App Store Connect display name is awaiting the owner's choice because `Fotoswipe` is already taken.

The Fotoswipe iOS build workflow validates the project, runs unit tests on an iPhone simulator and produces an unsigned iPhone archive. Signing and TestFlight delivery are not enabled in this validation workflow.
